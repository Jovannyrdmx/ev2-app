## 🐳 FULL SYSTEM WITH DOCKER (15 MINUTES)

### **Setup Commands**
```bash
# Navigate to project
cd /path/to/easyflirt-nightclub

# Copy config
cp .env.example .env

# Start everything
docker-compose up -d --build

# Wait 2-3 minutes...

# Open in browser
http://localhost:8080
```

### **Verify It's Running**
```bash
# Check status
docker-compose ps

# Test API
curl http://localhost:3000/health

# Test WebSocket
curl http://localhost:4000/health
```

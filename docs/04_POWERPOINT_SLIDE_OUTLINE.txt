## PRESENTATION TIPS

### Before Presenting
- Practice 20+ times
- Time yourself (45 minutes target)
- Test all links/demos
- Have backup internet
- Print one-pagers

### During Presentation
- Tell a story (problem → solution → traction)
- Use visuals, not bullet points
- Show passion & vision
- Listen to investor concerns
- Ask great questions

### After Presentation
- Send thank you email (24 hours)
- Share supporting docs
- Follow up weekly
- Move toward term sheet

# HOW TO CREATE THIS IN POWERPOINT

## Step 1: Open PowerPoint
- Create new blank presentation
- Set professional template

## Step 2: Design
- Use consistent color scheme (dark blue + light accent)
- Font: Helvetica, Arial, or Inter (clean fonts)
- One idea per slide
- High-quality images/icons

## Step 3: Add Content
- Copy slide text from this outline
- Add relevant charts/graphs
- Include your company logo
- Add team photos

## Step 4: Polish
- Ensure consistent formatting
- Add transitions (subtle)
- Test on projector
- Save as PDF backup

## Step 5: Present
- Use clicker/presenter view
- Make eye contact
- Tell the story naturally
- Be ready for questions

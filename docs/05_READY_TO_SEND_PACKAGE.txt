## 💾 FILES TO CONVERT TO PDF

### Converting to PDF (Easy Steps)

**Option 1: Use Microsoft Word**
1. Open the .md file in Word
2. File → Save As
3. Format: PDF
4. Save

**Option 2: Online Converter**
1. Go to: https://pandoc.org/ or https://cloudconvert.com/
2. Upload your .md file
3. Download as PDF
4. Done

**Option 3: Google Docs**
1. Go to: https://docs.google.com/
2. New → Upload file → Select .md file
3. File → Download → PDF

### How to Find Them

1. **LinkedIn:** Search "venture capitalist" + your city
2. **Crunchbase:** Filter by investment stage & vertical
3. **PitchBook:** Access through library
4. **AngelList:** Browse angel investors
5. **Your Network:** Ask for intros from mentors

### Email Best Practices

✅ **DO:**
- Use warm introductions only
- Personalize each email
- Keep subject line under 50 characters
- Keep body under 3 paragraphs
- Include clear call-to-action
- Follow up after 1 week
- Be authentic and genuine

❌ **DON'T:**
- Send cold emails (always get intro)
- Use generic/template emails
- Make the email about you (make it about them)
- Attach multiple files
- Expect immediate response
- Be pushy or aggressive
- Misspell investor's name

## 📞 PHONE CONVERSATION TIPS

When investor calls/meets:

**Opening (2 min):**
- "Thanks for taking the time"
- "I know you invest in SaaS/hospitality"
- "I think EV2 could be interesting for you"

**Problem (3 min):**
- Tell the nightclub pain point story
- Paint a vivid picture
- Make them feel the problem

**Solution (3 min):**
- Show how EV2 solves it
- Focus on customer benefits
- Use specific examples

**Proof (2 min):**
- Share traction/early customers
- Show metrics
- Build credibility

**Ask (1 min):**
- "Would you be interested in learning more?"
- "Can I send you our detailed plan?"
- "Would you like to see a demo?"

**Listen (Remaining time):**
- Ask questions
- Understand their concerns
- Address objections honestly

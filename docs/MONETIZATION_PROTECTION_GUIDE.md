## 💰 PHASE 3: PRICING STRATEGY (Week 3)

### **STEP 3.1: Define Pricing Models**

```
OPTION 1: FIXED PRICE PER CLUB
(Simplest)

Structure:
- One-time setup: $0 (included)
- Monthly license: $1,000-5,000 USD
- Technical support: Included
- Updates: Included

Example:
- Small club (50 tables): $1,000/month
- Medium club (100+ tables): $2,500/month
- Large club (200+ tables): $5,000/month

Calculation:
Per table: $10-25 USD/month

Advantages:
✅ Easy to explain
✅ Predictable budget
✅ Easy to bill

Disadvantages:
❌ Doesn't scale with actual usage
❌ May be unfair to small clubs

---

OPTION 2: COMMISSION-BASED PRICING
(Better for scaling)

Structure:
- Setup: $500 USD (one-time)
- Transaction commission: 2-5% of all transactions
  - Tips: 3%
  - Drink orders: 2%
  - Payments: 2%

Example:
- Club orders: $1,000 in drinks
- Commission: $20 (2%)
- Club pays: $1,020 total

Advantages:
✅ Scales with club growth
✅ Club wins = you win
✅ Aligned incentives

Disadvantages:
❌ Less predictable
❌ Requires payment processing

---

OPTION 3: HYBRID PRICING (RECOMMENDED)
(Best balance)

Structure:
- Setup: $1,000-5,000 USD (one-time)
- Base monthly: $500-2,000 USD
- Commission: 1-2% of transactions (if over threshold)

Example:
- Club A (small): $500/month + 1% transactions
- Club B (medium): $2,000/month + 1% transactions
- Club C (large): $5,000/month + 0.5% transactions

Advantages:
✅ Predictable (fixed base)
✅ Scales (with commission)
✅ Fair to all

---

OPTION 4: TIERED / VOLUME-BASED
(For resellers)

Structure:
- Tier 1 (1-3 locations): $2,000/month
- Tier 2 (4-10 locations): $1,500/month each = $6,000-15,000
- Tier 3 (11+ locations): $1,000/month each = $11,000+

Advantages:
✅ Incentivizes growth
✅ Resellers can profit at scale
✅ Predictable for volume

---

RECOMMENDATION FOR BEGINNERS:
Use Option 3 (Hybrid):
- Setup: $2,000-5,000 (one-time)
- Base: $1,000-3,000/month (per location)
- Commission: 2% of transactions

Benefits:
- Predictable revenue
- Scalability
- Fair to client
- Aligned incentives
```

## 💳 PHASE 4: PAYMENT SYSTEM (Week 3-4)

### **STEP 4.1: Integrate Stripe**

```javascript
// backend/routes/payment.js

const express = require('express');
const router = express.Router();
const stripe = require('stripe')(process.env.STRIPE_SECRET_KEY);

/**
 * Create checkout session
 */
router.post('/create-checkout-session', async (req, res) => {
  try {
    const { plan, licenseeId, licenseeEmail } = req.body;

    // Define plans
    const plans = {
      'startup': {
        name: 'EV2 Clandestinoz Startup',
        amount: 100000, // $1,000 USD in cents
        description: '1 Location, Up to 50 tables'
      },
      'professional': {
        name: 'EV2 Clandestinoz Professional',
        amount: 250000, // $2,500 USD
        description: '1 Location, Up to 150 tables, 3D + AI'
      }
    };

    const planInfo = plans[plan];

    if (!planInfo) {
      return res.status(400).json({ error: 'Invalid plan' });
    }

    // Create Stripe session
    const session = await stripe.checkout.sessions.create({
      payment_method_types: ['card'],
      line_items: [{
        price_data: {
          currency: 'usd',
          product_data: {
            name: planInfo.name,
            description: planInfo.description,
          },
          unit_amount: planInfo.amount,
        },
        quantity: 1,
      }],
      mode: 'subscription', // For recurring billing
      billing_address_collection: 'auto',

        licenseeId,

    });

    res.json({ sessionId: session.id });
  } catch (error) {

 * Stripe webhook
 */
router.post('/webhook', express.raw({type: 'application/json'}), async (req, res) => {
  const sig = req.headers['stripe-signature'];

  let event;

  try {
    event = stripe.webhooks.constructEvent(
      req.body,
      sig,
      process.env.STRIPE_WEBHOOK_SECRET
    );
  } catch (err) {
    res.status(400).send(`Webhook Error: ${err.message}`);
    return;
  }

  // Handle different events
  switch (event.type) {
    case 'checkout.session.completed':
      const session = event.data.object;
      // Create license in DB
      await createLicense(session.metadata.licenseeId, session.metadata.plan, session.id);
      break;

    case 'customer.subscription.updated':
      const subscription = event.data.object;
      // Update subscription
      await updateSubscription(subscription.metadata.licenseeId, subscription);
      break;

    case 'customer.subscription.deleted':
      const deletedSub = event.data.object;
      // Cancel license
      await cancelLicense(deletedSub.metadata.licenseeId);
      break;
  }

  res.json({received: true});
});

## 🚀 CÓMO FUNCIONA / HOW IT WORKS

### **Flujo Completo / Complete Flow**

```
1. CLIENTE ORDENA BEBIDA
   → Selecciona bebida
   → Elige recipiente
   → Confirma
   → Sistema obtiene GPS

2. SISTEMA PROCESA
   → Crea orden
   → Calcula ubicación
   → Encuentra mesero cercano
   → Calcula ruta óptima

3. MESERO RECIBE
   → Notificación + sonido + vibración
   → Ve información completa
   → Ve mapa con ubicación
   → Confirma recepción

4. MESERO DELIVERY
   → Recoge bebida en barra
   → Camina a cliente
   → Mapa actualiza en vivo
   → Cliente se mueve = mapa se actualiza

5. ENTREGA
   → Llega a cliente
   → Confirma entrega
   → Foto (opcional)
   → Propina acreditada

6. REGISTRO
   → Tiempo total guardado
   → Propina registrada
   → Ranking actualizado
   → Siguiente orden
```

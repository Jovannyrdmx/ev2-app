## 💻 HOW TO USE

### **Test Immediately**
```
1. Open: tip-dancers-system.html
2. You'll see 6 tabs:
   - 👩‍💼 Tip Hostesses
   - 🍹 Tip Bartenders
   - 👨‍💼 Tip Waiters
   - 💃 Tip Dancers
   - 🍹 Send Drinks
   - 🏆 Leaderboard
```

### **To Tip Someone**
```
1. Select staff category (Hostess, Bartender, Waiter, Dancer)
2. Click on staff member
3. Choose preset tip ($50-$500) OR enter custom amount
4. Confirm - tip is sent!
```

### **To Send a Drink (Dancers Only)**
```
1. Go to "Send Drinks" tab
2. Select dancer from dropdown
3. Choose drink from menu
4. Optionally add flirty message
5. Click "Send Drink"
6. Confirmation appears
```
